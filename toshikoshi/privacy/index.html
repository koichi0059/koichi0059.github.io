プライバシーポリシー

iOS アプリ 脱出ゲーム 年越しそば屋　制定 2026年11月28日

脱出ゲーム 年越しそば屋（以下「本アプリ」）は、氏名やメールアドレスなど、利用者を特定できる情報を集めません。 画面には Google の広告（AdMob）が表示され、広告の配信のために、Google が端末の情報を受け取ります。 広告は、買い切りの「広告を消す（ヒント見放題）」で表示しないようにできます。

1. 開発者が収集する情報

ありません。開発者は、氏名・メールアドレス・電話番号・連絡先・写真など、 利用者に関する情報を受け取りません。アカウントの登録もありません。

2. 端末内に保存される情報

遊びの進み具合（持ち物・解いた謎・いる場所・錠に入れかけた並び）、見たヒントの枚数、遊んだ時間、 音の大きさの設定は、続きから遊べるように端末内にのみ保存されます。 これらは開発者を含む第三者が閲覧することはできず、外部に送信されることもありません。 アプリを削除すると同時に消去されます。アプリの「はじめからやり直す」で、進み具合を消すこともできます。

クリアしたあとの「年賀の一枚」の画像は、端末の中で作られます。利用者が「年賀の一枚を送る」を選んだときだけ、 iOS の共有の機能で、利用者が選んだ相手やアプリに渡されます。開発者はその画像を受け取りません。

3. 広告（Google AdMob）

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を使って、バナー広告と、 ヒントの答えを開く前の動画広告を表示します。 広告の表示・不正防止・効果の測定のために、Google の SDK が次の情報を Google に送ることがあります。

  • IP アドレスから推定される、おおよその位置
  • 端末の識別子（ベンダー識別子 IDFV）、端末の種類、OS の版
  • トラッキングを許可した場合に限り、広告識別子（IDFA）
  • 広告の表示やタップなど、広告とのやり取り
  • アプリの動作の不具合に関する情報（診断）

広告を初めて表示する前に、iOS の「トラッキングの許可」（App Tracking Transparency）を一度だけお尋ねします。 許可した場合に限り、Google が広告識別子（IDFA）を使い、利用者の興味に合わせた広告を表示することがあります。 許可しない場合は、広告識別子を使わず、興味に合わせない広告を表示します。許可しなくても、遊べる内容は変わりません。 許可はいつでも iOS の「設定」＞「プライバシーとセキュリティ」＞「トラッキング」から変えられます。 開発者がこれらの情報を受け取ったり、氏名などの個人情報と結び付けたりすることはありません。 広告の内容は、すべての年齢に適したものに限っています。 Google による情報の取り扱いは、Google のパートナーのサイトやアプリでのデータの使用 と Google プライバシー ポリシー をご覧ください。

4. 通信

本アプリが通信するのは、広告を表示するとき（Google）と、「広告を消す（ヒント見放題）」の購入・復元のとき（Apple の App Store）だけです。 謎解きそのものは通信なしで遊べます。通信できないときは、広告が表示されないだけです。

5. アプリ内課金（広告を消す・ヒント見放題）

「広告を消す（ヒント見放題）」の購入と復元は、Apple の App Store の仕組みで行われます。支払いの情報は Apple が扱い、 開発者は受け取りません。購入したかどうかは、端末と App Store の間で確かめます。

6. 第三者への提供

開発者が第三者に利用者の情報を提供することはありません（上の 3 の広告配信を除き、開発者が受け取る情報もありません）。

7. お子様の利用について

本アプリはすべての年齢を対象にしています。広告の内容は、すべての年齢に適したものに限っています。興味に合わせた広告は、トラッキングを許可した場合だけです。

8. 本ポリシーの変更

本ポリシーの内容を変更する場合は、このページを更新します。アプリの機能追加に 伴って情報の取り扱いが変わる場合には、変更後のアプリを配信する前に本ページを 更新します。

9. お問い合わせ

本ポリシーおよび本アプリについてのお問い合わせは、 GitHub の Issues よりお願いします。
