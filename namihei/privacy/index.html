プライバシーポリシー

iOS アプリ ナミヘイ　制定 2026年8月5日

ナミヘイは、利用者の情報を一切収集しません。 ゲームの処理はすべて端末の中だけで完結します（購入と復元のときだけ App Store と通信します）。

1. 収集する情報

ありません。本アプリは、氏名・メールアドレス・電話番号・位置情報・連絡先・ 写真・端末識別子など、利用者に関するいかなる情報も収集しません。

2. 端末内に保存される情報

ルーレットの項目や人数などの設定は、利用の利便のために端末内にのみ保存されます。 これらは開発者を含む第三者が閲覧することはできず、外部に送信されることもありません。 アプリを削除すると同時に消去されます。

3. 通信

ゲームを遊ぶ際、本アプリはネットワーク通信を行いません。利用状況が外部のサーバーへ 送信されることはありません。

ただし、ジャンルの解放（アプリ内課金）の購入と復元の際には、Apple の App Store と 通信します。この通信は Apple が提供する仕組み（StoreKit）によるもので、決済や購入履歴は Apple が管理します。開発者が決済情報や購入者の情報を受け取ることはありません。

4. 第三者への提供

収集する情報が存在しないため、第三者に提供する情報もありません。

5. 広告・アクセス解析

本アプリは広告を表示しません。また、アクセス解析ツールや行動追跡（トラッキング） の仕組みを一切使用していません。広告識別子（IDFA）も利用しません。

6. 外部サービス・SDK

本アプリは、Apple が iOS の一部として提供する標準の機能のみで構成されており、 第三者が提供する SDK やサービスを組み込んでいません。

7. お子様の利用について

本アプリは情報を収集しないため、年齢にかかわらず、利用者の情報が取得される ことはありません。

8. 本ポリシーの変更

本ポリシーの内容を変更する場合は、このページを更新します。アプリの機能追加に 伴って情報の取り扱いが変わる場合には、変更後のアプリを配信する前に本ページを 更新します。

9. お問い合わせ

本ポリシーおよび本アプリについてのお問い合わせは、 GitHub の Issues よりお願いします。
