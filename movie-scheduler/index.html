動画予約ツール　個人利用のデスクトップツール

自分の YouTube チャンネルに上げた動画へ、説明文やタグを設定し、公開日時を予約するための 個人用ツールです。作者の手元の Mac で動くスクリプトで、一般には配布していません。

できること

  • 自分がアップロードした動画の一覧を取得する
  • タイトル・説明文・タグ・カテゴリを設定する
  • 公開日時を予約する（非公開のまま指定時刻に公開）
  • 自分の動画にコメントを投稿する

いずれも作者本人のチャンネルに対してのみ行います。 他人のチャンネルや動画を操作することはありません。

使用する Google の権限

Google アカウントでのログイン時に、次の権限を求めます。

  • https://www.googleapis.com/auth/youtube.force-ssl — 自分の YouTube アカウントの動画情報の取得・更新、およびコメントの投稿に使用します。

動作環境

macOS 上の Python スクリプトとして動作します。サーバーはありません。 ログインで得たトークンは、作者のパソコンの中だけに保存されます。
