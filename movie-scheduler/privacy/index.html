プライバシーポリシー

デスクトップツール 動画予約ツール　制定 2026年9月20日

動画予約ツールは、作者本人のみが使う個人用ツールです。 利用者から情報を集めることはなく、サーバーも持ちません。Google から取得した情報は、 すべて作者のパソコンの中だけで扱われます。

1. 本ツールについて

本ツールは、作者が自分の YouTube チャンネルを運用するために作った、 macOS 上で動作するスクリプトです。一般に配布しておらず、作者以外の利用者はいません。

2. アクセスする Google ユーザーデータ

Google アカウントでの認証時に、次の権限を求めます。

  • https://www.googleapis.com/auth/youtube.force-ssl

この権限は、次の目的にのみ使用します。

  • 自分がアップロードした動画の一覧および現在の設定を読み取る
  • 動画のタイトル・説明文・タグ・カテゴリ・公開日時を書き換える
  • 自分の動画にコメントを投稿する

上記以外の目的（広告、プロファイリング、機械学習モデルの学習など）には使用しません。

3. 情報の保存

認証で得たアクセストークンおよびリフレッシュトークンは、作者のパソコンの ホームディレクトリ配下に、本人だけが読み書きできる権限で保存されます。 外部のサーバーへ送信することはありません。

動画のタイトルや説明文など、YouTube から取得した内容は、作業中に一時的に 手元のファイルへ書き出されることがありますが、これも同じパソコンの中に留まります。

4. 第三者への提供

取得した情報を第三者へ提供・販売・共有することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取る情報の使用および他者への移転は、 Google API Services User Data Policy （限定使用の要件を含む）に準拠します。

6. 広告・アクセス解析

本ツールは広告を表示せず、アクセス解析や行動追跡の仕組みも使用していません。

7. アクセス権の取り消しと削除

本ツールに与えた権限は、 Google アカウントの「サードパーティ製アプリとサービス」 からいつでも取り消せます。取り消すと、本ツールは以後 YouTube の情報にアクセスできません。 手元に保存されたトークンは、該当ファイルを削除することで消去されます。

8. 本ポリシーの変更

内容に変更があった場合は、このページを更新します。

9. お問い合わせ

本ポリシーおよび本ツールについてのお問い合わせは、 GitHub の Issues よりお願いします。
